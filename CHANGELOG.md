# Changelog

Все заметные изменения проекта будут документироваться в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
а проект использует [Semantic Versioning](https://semver.org/lang/ru/).

## 0.2.0 - 2026-09-19

### Добавлено

- Настраиваемое поведение при сворачивании: окно можно оставить на панели
  задач или скрыть в системный трей.
- Защита от запуска нескольких экземпляров приложения: повторный запуск
  возвращает уже открытое главное окно.
- В боковую панель добавлена явная команда выхода из приложения.
- Руководство пользователя с разделами о подключениях, настройках,
  плавающем окне и устранении неполадок.

### Изменено

- Echo сосредоточен на своей основной задаче — приёме сообщений по SSE и
  отображении состояния подключений; устаревшие серверные поверхности удалены.
- Настройки подключений и окон проверяются перед сохранением, записываются
  атомарно и восстанавливаются из резервной копии при повреждении основного
  файла.
- SSE-подключения получили более надёжное переподключение, ограничение размера
  входящих событий и более подробную диагностику ошибок.
- Название TTSBard Echo приведено к единому виду во всём интерфейсе:
  заголовки окон, системный трей, диалоги подключения и заголовок страницы.
- Настройки сгруппированы по разделам «Поведение окон», «Диагностика» и
  «Сообщения»; размеры боковой панели переведены на общие CSS-переменные.
- Проверки релизной сборки, frontend-тесты и документация разработки приведены
  в соответствие с актуальной архитектурой проекта.

### Исправлено

- Стабилизированы восстановление позиции и размера нативных окон, запуск
  скрытого главного окна и сохранение состояния между запусками.
- Плавающее окно корректно подстраивает высоту под список подключений.
- Усилены инварианты настроек и состояния подключений.
- Кнопки, состоящие только из значка, получили доступные текстовые подписи.
- Вкладка «Общие» в настройках использует значок шестерёнки вместо
  похожего символа ползунков.

## 0.1.0 - 2026-08-13

### Добавлено

- Первая альфа-версия TTSBard Echo для Windows.
- Подключение к HTTP(S)-потокам Server-Sent Events с необязательным токеном
  доступа.
- Главное окно для настройки подключений и просмотра входящих сообщений.
- Компактное плавающее окно для отображения активности подключений.
- Системный трей и сохранение пользовательских настроек между запусками.
