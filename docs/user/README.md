# Руководство пользователя

## Первый запуск

1. Запустите Echo. Автоматически откроется экран подключений.
2. Нажмите **Добавить подключение** и укажите название, SSE-адрес `http://` или `https://`, а также необязательный токен доступа.
3. Нажмите **Подключить**. Карточка покажет состояние подключения: отключено, подключение, подключено или ошибка.

## Плавающее окно

Нажмите кнопку плавающего окна в заголовке приложения или выберите его в меню трея. Чтобы переместить окно, перетащите его за заголовок. Кнопка «минус» скрывает окно. Если окно оказалось за пределами экрана, откройте **Настройки → Интерфейс → Восстановить позицию**.

Режим кликабельности отключает взаимодействие мышью с плавающим окном. Перед перемещением или настройкой окна отключите его в разделе **Настройки → Интерфейс**.

## Настройки и устранение проблем

В разделе **Интерфейс** можно изменить тему, цвет плавающего окна, прозрачность, режим кликабельности и позицию окна. При ошибке подключения проверьте доступность адреса, правильность токена и наличие документированного SSE-потока на сервере. Токены не отображаются в карточках и статусах подключения.

## Повторный запуск и выход

В одном сеансе Windows работает одна копия Echo. Повторный запуск через EXE,
ярлык или меню «Пуск» показывает и активирует уже работающее главное окно, не
сбрасывая подключения и текущие сообщения.

В заголовке главного окна нет кнопки закрытия: кнопка «минус» сворачивает окно,
но по умолчанию оставляет его на панели задач. Настройка **Скрывать с панели
задач при сворачивании** переводит свёрнутое окно только в tray. Для полного
завершения используйте кнопку **Выход** в нижней части сайдбара или пункт
**Выход** в меню tray.
