# Настройки и работа в фоне

## Общие

- **Скрывать с панели задач при сворачивании** — если выключено, главное окно
  остаётся свёрнутым на панели задач; если включено, оно скрывается в трей.
  Подключения продолжают работать в обоих режимах.
- **Включить логирование** — записывает диагностическую информацию с выбранным
  уровнем. Для применения требуется перезапуск Echo.
- **Скрыть от захвата экрана** — просит Windows исключить окна Echo из системных
  средств записи. Для применения требуется перезапуск.
- **Очищать сообщения через** — задаёт время показа последнего сообщения от 1
  до 3600 секунд.

## Интерфейс

Вкладка **Интерфейс** меняет светлую или тёмную тему, цвет и прозрачность
плавающего окна. Своя тема плавающего окна применяется только после включения
переключателя **Использовать свою тему**.

## Сворачивание, трей и выход

В заголовке главного окна нет кнопки закрытия. Кнопка «минус» сворачивает окно
согласно выбранной настройке. Главное окно можно вернуть с панели задач, через
меню трея или повторным запуском Echo.

В одном сеансе Windows работает одна копия Echo. Повторный запуск показывает и
активирует уже работающую копию, не сбрасывая подключения и сообщения.

Для полного завершения используйте **Выход** в боковой панели или меню трея.
