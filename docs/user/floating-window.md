# Плавающее окно

Плавающее окно показывает состояние и последнее сообщение каждого подключения,
не открывая основное окно Echo. Высота автоматически подстраивается под список
подключений.

## Показать или скрыть

Нажмите кнопку с изображением окна в заголовке Echo либо используйте меню
системного трея. Кнопка «минус» в плавающем окне только скрывает его.

Чтобы переместить окно, перетащите свободную область окна левой кнопкой мыши.
Положение сохраняется между запусками.

## Пропуск кликов

Кнопка с изображением мыши в заголовке основного окна включает пропуск кликов.
В этом режиме мышь взаимодействует с программами под плавающим окном, поэтому
само окно нельзя перетащить. Для перемещения сначала выключите пропуск кликов
той же кнопкой в основном окне.

## Внешний вид

В разделе **Настройки → Интерфейс** доступны:

- светлая и тёмная тема приложения;
- свой цвет фона плавающего окна;
- прозрачность от 0 до 90 процентов.

Изменения применяются к плавающему окну сразу и сохраняются между запусками.
