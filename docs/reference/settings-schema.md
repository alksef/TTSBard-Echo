# Settings schema

The public settings snapshot contains `connections`, `logging`, `hotkeys`, `general`, and `windows`. `windows.floating` contains `opacity` (backend 10–100), `bg_color` (`#RRGGBB`), `clickthrough`, `use_custom_color`, `visible`, and optional `x`/`y`. General settings contain theme (`dark` or `light`), `exclude_from_capture`, `hide_on_minimize` (default `false`), and `message_clear_interval_seconds`.
