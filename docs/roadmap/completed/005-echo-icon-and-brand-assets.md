# 005 — Echo icon and brand assets

- **Статус:** completed
- **Зависимость:** 001 для утверждённой палитры и titlebar integration
- **Можно выполнять параллельно:** 002, 003
- **Блокирует:** финальную документацию 007

## Результат

Echo получает собственный компактный знак, родственный TTSBard, но отличимый от него.
Создаётся канонический векторный source и полный проверенный набор Tauri/Windows assets.

## Текущее состояние

`src-tauri/icons/icon.ico` Echo — старый синий динамик. Его SHA-256 совпадает со старым
`src-tauri/icon.ico` из app-tts-v2, поэтому это не уникальная айдентика Echo.

Актуальный TTSBard использует центральную waveform и симметричные расходящиеся дуги.
Эта геометрическая идея подходит как родительская связь, но текущий чёрный прозрачный
вариант нельзя копировать напрямую: он плохо читается на тёмной панели Windows.

## Основное направление: Echo Ripple

- Центр: короткая упрощённая waveform, родственная TTSBard.
- Повтор: одна или две затухающие дуги/волны.
- Основной цвет: актуальный accent дизайн-системы, ориентир `#1D8CFF`.
- Вторичный слой: более светлый cyan/blue, ориентир `#70D6FF`.
- Геометрия остаётся узнаваемой в 16×16; дальние детали удаляются в small-size master.
- Знак должен работать без текста.

## Альтернативы для сравнения

1. `Double Wave` — две waveform со сдвигом и затуханием.
2. `Echo E` — геометрическая E, переходящая в звуковые дуги.

Перед финализацией сделать три одноцветных silhouette proof, а затем развивать только
выбранное направление. Не генерировать десятки стилистических вариантов.

## Объём работ

### 1. Готовые ресурсы

Рабочие исходники знака использовались при подготовке и не входят в публичный
репозиторий. Готовые ресурсы поставки находятся в `src-tauri/icons/`, а иконка
веб-интерфейса — в `public/app-icon.png`.

### 2. Size variants

- Для больших размеров используется полный вариант знака.
- Для 16–32 px используется упрощённый вариант.
- На 16 px оставить только детали, сохраняющие силуэт.
- Проверить pixel alignment вертикальных/горизонтальных границ и толщину линий.

### 3. Contrast

Проверить знак:

- на светлом и тёмном Windows taskbar;
- на светлом и тёмном фоне titlebar;
- в disabled/monochrome preview установщика;
- при системном scaling.

Если прозрачный двухцветный знак не обеспечивает контраст, использовать компактную
тёмную/светлую подложку или нейтральный outline. Не полагаться на тонкую чёрную линию.

### 4. Generated assets

Из утверждённого SVG сгенерировать стандартный Tauri icon set, а не масштабировать
старый ICO вручную:

```text
src-tauri/icons/
├── 32x32.png
├── 128x128.png
├── 128x128@2x.png
├── icon.png
├── icon.ico
├── icon.icns
└── platform square assets, если их генерирует используемый Tauri workflow
```

- Использовать штатный Tauri icon generation workflow или воспроизводимый script.
- Проверить, что `tauri.conf.json` ссылается на фактически существующий комплект.
- Не оставлять единственным asset только ICO при bundle target `all`.

### 5. Product integration

- Использовать знак в titlebar только если он читается при 16–20 px; иначе оставить
  titlebar текстовым.
- Обновить bundle/install/taskbar/tray assets.
- Проверить tray отдельно: Windows может кэшировать старую иконку.

## Не входит

- Полный брендбук и маркетинговый сайт.
- Анимация логотипа.
- Изменение названия продукта.
- Копирование чёрного raster TTSBard как иконки Echo.

## Приёмка

- Иконка визуально родственна TTSBard и при этом не выглядит тем же приложением.
- Силуэт узнаваем в 16, 20, 32, 128 и 256 px.
- Контраст достаточен на светлом и тёмном фоне.
- Нет динамика, микрофона, мелкого текста или неразличимой сложной waveform.
- Репозиторий содержит SVG source и полный generated set.
- Debug/release bundle использует новую иконку; tray/taskbar не используют старый ICO.

## Верификация

- Контактный лист размеров 16/20/32/48/128/256 на white, dark и transparent/checker.
- Визуальная проверка tray, taskbar, window switcher и installer.
- Проверка alpha channel и отсутствия цветной каймы.
- Debug bundle smoke test.
- Проверка `git diff`, что generated assets относятся только к утверждённому source.
