# 015 — Стабильный размер floating и очистка основного UI

- **Статус:** completed
- **Приоритет:** P1
- **Зависимости:** 004, 009, 011

## Цель

Устранить рывки плавающего окна при попытке растянуть его вниз и убрать
служебный экспорт диагностики из минимальной панели подключений.

## Реализация

- Высота floating закрепляется одинаковыми native min/max constraints и
  меняется только вслед за высотой содержимого.
- Ширина остаётся доступной для ручного изменения от 300 до 10 000 logical px.
- Обработчик resize больше не борется с допустимым вертикальным drag: Windows
  не начинает такое изменение размера.
- Кнопка и frontend-состояния экспорта диагностики удалены из панели
  подключений.
- Backend-команда `export_diagnostics` и безопасный allowlist-формат сохранены
  как внутренняя диагностическая возможность и не вызываются интерфейсом.

## Не входит

- Изменение содержимого карточек floating или альтернативные layouts.
- Удаление backend-диагностики и её тестов.
- Изменение настроек lifecycle главного окна.
