# 016 — Заголовок и сворачивание главного окна

- **Статус:** completed
- **Приоритет:** P1
- **Зависимости:** 013, 014
- **Источник паттерна:** `app-tts-v2`, ROADMAP-092

## Цель

Убрать неоднозначную кнопку закрытия из заголовка и сделать обычное сворачивание
видимым на панели задач, оставив скрытие в tray явной пользовательской настройкой.

## Согласованное поведение

- В заголовке остаётся кнопка **Свернуть**; крестика закрытия нет.
- Новое поле `general.hide_on_minimize` имеет default `false` и безопасно
  добавляется к существующим файлам настроек через serde default.
- При `false` обычное сворачивание оставляет Echo на панели задач.
- При `true` то же сворачивание дополнительно скрывает главное окно в tray.
- Изменение применяется со следующего сворачивания без перезапуска.
- Полный выход остаётся в сайдбаре и tray, а повторный запуск восстанавливает
  существующее окно через single-instance механизм.
