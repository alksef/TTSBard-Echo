# 014 — Выход из приложения в сайдбаре

- **Статус:** completed
- **Приоритет:** P2
- **Зависимости:** 009, 013
- **Источник паттерна:** `app-tts-v2`, `src/components/Sidebar.vue`

## Цель

Перенести явное полное завершение Echo из заголовка главного окна в нижнюю
часть сайдбара, чтобы системные кнопки заголовка отвечали только за окно, а
выход из фонового приложения находился рядом с основной навигацией.

## Согласованное поведение

- В развёрнутом сайдбаре отображаются иконка и подпись **Выход**.
- В свёрнутом сайдбаре остаётся иконка с tooltip и доступным именем **Выход**.
- Нажатие вызывает существующую backend-команду `quit_app` ровно один раз и
  блокируется до завершения запроса.
- При ошибке команда становится доступна для повторной попытки.
- Из заголовка удаляется только кнопка полного выхода.
- Крестик продолжает скрывать главное окно в tray, а кнопка сворачивания
  сохраняет прежнее поведение.

## Не входит

- Изменение backend-команды `quit_app` или события `app-exit`.
- Изменение tray menu и single-instance lifecycle.
- Диалог подтверждения выхода, новая настройка или переработка сайдбара.

## Критерии готовности

- В заголовке нет кнопки полного выхода и вызова `quit_app`.
- Кнопка **Выход** доступна в обоих состояниях сайдбара.
- Повторное нажатие во время запроса не создаёт второй IPC-вызов.
- Ошибка IPC не оставляет кнопку заблокированной.
- Компонентные тесты и production-сборка frontend проходят.

## Проверка

- Ручной smoke: развёрнутый/свёрнутый сайдбар, скрытие крестиком и полное
