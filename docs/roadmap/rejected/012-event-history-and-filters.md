# 012 — История, поиск и фильтры событий

- **Статус:** rejected
- **Решение:** 2026-09-16

## Почему отклонено

История на диске, панель событий, поиск, фильтры и несколько floating layouts
превращают Echo в отдельный журнал событий и не нужны для его основной задачи:
показать текущие сообщения от нескольких экземпляров TTSBard.

Реализация roadmap 012 была удалена целиком; компактное floating-окно снова
показывает состояние и последнее актуальное сообщение каждого подключения без
дополнительного хранилища и навигации.

## Условие пересмотра

Возвращаться к направлению можно только после отдельного пользовательского
запроса с конкретным сценарием, который нельзя решить отображением текущего
сообщения.
