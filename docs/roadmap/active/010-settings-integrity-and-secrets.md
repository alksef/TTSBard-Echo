# 010 — Целостность и безопасность настроек

- **Статус:** proposed, требуется утверждение хранения секретов
- **Приоритет:** P0
- **Зависимости:** 008
- **Блокирует:** 013

## Результат

Сбой записи не повреждает настройки, access tokens не хранятся открытым текстом,
а WebView работает с явной Content Security Policy.

## Проблема

`settings.json` перезаписывается напрямую и содержит access token. При сбое
между открытием и завершением записи файл может стать неполным. В Tauri config
сейчас установлено `"csp": null`.

## Решение, требующее выбора

Предпочтительный Windows-вариант — хранить token через Credential Manager или
DPAPI, а в JSON оставлять только ссылку/идентификатор. Более простой вариант —
DPAPI-шифрование значения прямо в JSON. Формат необходимо закрепить ADR до
реализации миграции.

## Объём работ

1. Ввести атомарную запись settings/windows: temporary file, flush, replace и
   восстановление последнего корректного состояния.
2. Добавить версию схемы и миграцию существующего plaintext token.
3. Исключить token из runtime snapshots, ошибок, debug formatting и frontend
   events, где он не нужен.
4. Ограничить права файла конфигурации средствами Windows, где это применимо.
5. Включить CSP, достаточную для локальных assets и необходимых Tauri IPC.
6. Добавить диагностическое сообщение для повреждённого конфига без вывода
   секретного содержимого.

## Не входит

- Облачная синхронизация секретов.
- Общий password manager для других приложений TTSBard.
- Изменение серверной схемы аутентификации.

## Приёмка

- Прерванная/ошибочная запись сохраняет последний валидный config.
- После миграции plaintext token отсутствует в `settings.json`.
- Обновление, удаление и повторное добавление token работают предсказуемо.
- CSP не блокирует основное и floating окна и не разрешает лишние источники.
- Логи, IPC snapshots и пользовательские ошибки не раскрывают token.

## Верификация

- Rust unit tests атомарной записи, миграции и recovery;
- negative tests на token leakage;
- frontend contract tests после изменения DTO;
- `npm test`, `npm run build`, Rust fmt/Clippy/tests;
- ручная миграция копии реального v0.1.0 config и проверка двух окон.
