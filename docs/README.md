# Документация TTSBard Echo

TTSBard Echo — Windows-приложение на Tauri для отображения сообщений, которые
озвучиваются в TTSBard и поступают из его WebView/SSE-потока. Текущие сообщения
показываются в компактном плавающем окне во время общения.
