# TTSBard Echo

TTSBard Echo — Windows-приложение для отображения сообщений, которые
озвучиваются в TTSBard. Оно подключается к TTSBard через внешний адрес и
показывает сообщения во время общения в компактном плавающем окне поверх
других приложений.

К Echo можно подключить один или несколько экземпляров TTSBard. В основном
окне настраиваются подключения и отображается их состояние, а плавающее окно
показывает текущие озвучиваемые сообщения. Если в TTSBard включена передача
набора, то в плавающем окне отображается и процесс набора текста.

## Использование

1. В TTSBard откройте **WebView**.
2. Выберите адрес `0.0.0.0`, укажите порт (по умолчанию `10100`), сохраните
   настройки и запустите WebView-сервер.
3. В блоке **Внешнее подключение** создайте токен доступа и включите **UPnP**.
4. Получите и скопируйте внешний URL из этого блока.
5. В TTSBard Echo нажмите **Добавить подключение**, вставьте внешний URL и нажмите
   **Проверить**, затем **Добавить** и **Подключить**.
6. В TTSBard выберите маршрут отправки, включающий WebView. Озвучиваемые через
   этот маршрут сообщения появятся в плавающем окне TTSBard Echo.

Разрешите TTSBard входящие подключения в брандмауэре Windows. UPnP должен
поддерживаться и быть включён на роутере; если автоматический проброс не
сработал, настройте проброс выбранного TCP-порта вручную. Подробности приведены
в [руководстве пользователя](docs/user/guide.md).
